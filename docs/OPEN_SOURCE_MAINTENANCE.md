# Open-Source Maintenance

This project is maintained as a reusable, context-safe skill for AI-assisted software development.

## Maintenance focus

Maintainers prioritize reproducible failure cases, context-management regressions, work-item quality, GitHub integration safety, verification quality, and documentation accuracy.

## Evidence policy

Stars, forks, downloads, and external adoption are reported only when they can be verified. Maintenance quality is demonstrated through useful issues, reviewed changes, tests, validation, and reproducible releases rather than manufactured activity.

## AI-assisted maintenance

AI tools may assist with triage, review, test generation, and release preparation. Final authorization, security decisions, and release approval remain maintainer responsibilities.
